# robertus.xyz — Claude Instructions

## Git workflow

- Always commit and push directly to `main`.
- Do NOT create feature branches unless explicitly asked.
- After every change, commit with a clear message and push immediately.

## Automation-managed files

`content/` is normally overwritten wholesale by `publish.sh`, which rsyncs the
Obsidian vault over it with `--delete`. Pages generated by automation instead of
by the vault must be listed in `AUTOMATED_PAGES` in `publish.sh`, or they are
deleted on the next publish. Currently: `content/bookmarks.md`.

The X bookmarks pipeline lives in `automation/x-bookmarks/` — see the README
there before changing any of it.
